# SNOWFALL ❄️

A polished Android seasonal customization app focused on winter. Native Jetpack Compose UI, animated snowfall preview, winter controls, and a live wallpaper service.

## Build
Open this repository in Android Studio, or download the APK produced by GitHub Actions from the Actions tab.

- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
- Compose Material 3
- Minimum Android 8.0 (API 26)

## Features
- Winter-themed dashboard with animated snow preview
- Snow intensity and speed controls
- Live wallpaper preview/apply flow
- Wallpaper service for actual home-screen snowfall
- Settings page with toggles and theme options

Android system UI such as the notification shade and Settings cannot be fully reskinned by an ordinary third-party app; Snowfall uses supported wallpaper and launcher customization instead.
